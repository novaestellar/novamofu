# 反AI感检查清单 (Anti-AI Checklist)

在输出提示词之前,自动检查以下项目。如果任何一项不通过,需要修改提示词。

## 检查项目

### 1. 角色一致性 ✅/❌

- [ ] 角色外貌描述是否具体?(年龄、体型、发型、服装)
- [ ] 角色在整个视频中是否保持一致?
- [ ] 是否有明确的身份特征?(不能只是"一个女人")

### 2. 地点具体性 ✅/❌

- [ ] 地点是否具体到可以想象?(不能只是"一个街道")
- [ ] 是否包含时代元素?(年代感)
- [ ] 是否有环境细节?(光影、天气、声音)

### 3. 摄像缺陷 ✅/❌

- [ ] 是否指定了设备类型?(参见 device-aesthetics.md)
- [ ] 是否描述了画面缺陷?(噪点、抖动、畸变)
- [ ] 是否包含了负面约束?(告诉模型"不要做什么")

### 4. 时间轴非完美事件 ✅/❌

- [ ] 时间轴中是否有非完美事件?
- [ ] 是否有镜头晃动/对焦失灵/曝光变化?
- [ ] 是否有"生活化"的意外?(路人经过、车辆遮挡)

### 5. 音频对应 ✅/❌

- [ ] 音频是否与画面对应?
- [ ] 是否有环境音?(不能只有音乐)
- [ ] 是否避免了"完美配乐"?

### 6. 负面约束完整性 ✅/❌

- [ ] 是否明确告诉模型"不要做什么"?
- [ ] 是否避免了以下AI默认行为:
  - 完美构图
  - 电影感运镜
  - 商业调色
  - 干净画面
  - 对称构图
  - 稳定画面

### 7. 整体真实感 ✅/❌

- [ ] 提示词读起来像在描述一段真实存在的视频?
- [ ] 还是像在描述一个理想化的AI生成画面?
- [ ] 是否有"这段素材是谁拍的"的答案?

## 常见AI感特征(需要避免)

| 特征 | 为什么假 | 如何修改 |
|------|----------|----------|
| "cinematic" | 真实视频不是电影 | 指定设备类型,描述缺陷 |
| "ultra realistic" | 真实视频不需要说"真实" | 描述具体的缺陷和不完美 |
| "4K" | 真实视频不一定4K | 指定设备的分辨率特征 |
| "beautiful lighting" | 真实布光不完美 | 描述自然光的变化和不完美 |
| "perfect composition" | 真实构图不完美 | 描述手持抖动和构图偏移 |
| "smooth camera movement" | 真实镜头不平稳 | 描述抖动和滞后 |
| "professional" | 真实视频不专业 | 指定非专业设备 |

## 自动检查流程

```
1. 生成提示词
2. 逐项检查清单
3. 如果任何一项不通过:
   a. 识别问题
   b. 修改提示词
   c. 重新检查
4. 所有项通过 → 输出最终提示词
```

## 示例修改

**修改前(有AI感):**
```
Cinematic shot of a woman walking down a beautiful street,
perfect lighting, smooth camera movement, 4K quality.
```

**修改后(真实感):**
```
智能手机竖屏拍摄,9:16竖构图,一个30岁女性走在纽约街头,
阳光从建筑间洒下,曝光在阴影和阳光间波动,镜头随着走路轻微上下浮动,
偶尔有路人经过遮挡画面,远处有汽车喇叭声。
没有三脚架。没有专业布光。没有完美构图。
```
