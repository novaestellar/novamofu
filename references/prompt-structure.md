# 7段式提示词结构 (7-Segment Prompt Structure)

NovaMoFu 使用7段式结构生成高质量视频提示词。每个段落回答一个特定问题,组合起来形成完整的视频描述。

## 结构概览

| # | 段落 | 回答的问题 | 必填 |
|---|------|-----------|------|
| 1 | 主要角色 | 谁出现在画面里? | ✅ |
| 2 | 地点 | 在哪里拍的? | ✅ |
| 3 | 视觉风格 | 什么气质? | ✅ |
| 4 | 摄像风格 | 用什么设备拍的? | ✅ |
| 5 | 时间轴 | 每个镜头发生了什么? | ✅ |
| 6 | 音频 | 听到什么声音? | ⚠️ 可选 |
| 7 | 目标 | 最终要像什么? | ✅ |

## 详细说明

### 1. 主要角色

回答: 谁出现在画面里,外貌和服装如何保持一致

**要求:**
- 具体描述外貌(年龄、体型、发型、服装)
- 强调一致性(整个视频中保持不变)
- 如果没有人物,描述主体(物体、动物、场景)

**示例:**
```
主要角色:
一名30岁左右的纽约上班族,深灰色羊毛大衣,白色棉质衬衫,
黑色直筒长裤,左手拿着纸质咖啡杯,右肩背着黑色通勤包。
短发被晨风吹得有几缕贴在额头,脸上有真实皮肤纹理和轻微疲惫感。
在整个视频中保持一致的身份、服装、发型和外貌。
```

### 2. 地点

回答: 在哪里拍的,具体空间、时代元素、光影和环境细节

**要求:**
- 具体到可以想象的细节
- 包含时代元素(年代感)
- 描述光影和环境

**示例:**
```
地点:
清晨7点半的纽约曼哈顿街角,人行道边有湿润的柏油路面、
黄色出租车、冒着热气的下水井盖、早餐餐车、不锈钢咖啡壶、
红绿灯按钮、地铁站楼梯口和刚升起的阳光。
```

### 3. 视觉风格

回答: 什么气质,真实感层级

**要求:**
- 确定真实感层级(纪录片/家庭录像/监控/电影)
- 描述整体视觉气质
- 指定色彩和对比度特征

**示例:**
```
视觉风格:
2020年代智能手机拍摄的真实感。轻微HDR处理,
色彩自然但不完美,对比度中等,有轻微的数字噪点。
不是电影画面,不是广告片,是路人随手拍到的真实片段。
```

### 4. 摄像风格

回答: 用什么设备拍的,有什么缺陷

**要求:**
- 指定设备类型(参见 device-aesthetics.md)
- 描述画面缺陷(这是关键!)
- 包含负面约束(关闭AI默认审美)

**示例:**
```
摄像风格:
智能手机竖屏拍摄,9:16竖构图,轻微过度锐化和HDR处理感,
走路时画面有上下浮动,光线从阴影切到阳光时曝光短暂波动。
没有横屏。没有三脚架稳定。没有专业布光。
没有电影感运镜。没有完美构图。
```

### 5. 时间轴

回答: 每个镜头发生了什么(10-15秒内)

**要求:**
- 按时间顺序描述
- 每个镜头2-4秒
- 包含"非完美事件"(这是去AI感的关键!)

**非完美事件示例:**
- 镜头稍微晃动
- 自动对焦短暂失灵
- 曝光突然变化
- 手指擦过镜头边缘
- 画面垂下拍到地面
- 突然关机/切黑

**示例:**
```
时间轴:
00:00-00:02 镜头从地铁站出口抬起,先拍到湿润的人行道,再对准街角。
00:02-00:04 上班族从地铁口走出来,下水井盖冒出的白色蒸汽从他腿边飘过。
00:04-00:06 他停在斑马线前看红灯,阳光从两栋楼之间落到大衣肩部,曝光突然变亮又恢复。
00:06-00:08 绿灯亮,他开始过马路,镜头跟着他移动,稍微滞后了一拍。
00:08-00:10 他走到马路中间,一辆黄色出租车从画面右侧驶过,遮挡了半秒。
00:10-00:12 他走过出租车,继续往前走,镜头垂下拍到自己的鞋尖,然后迅速抬起。
```

### 6. 音频

回答: 听到什么声音,如何对应画面

**要求:**
- 环境音(街道、室内、自然)
- 动作音(脚步、开门、说话)
- 与画面对应

**示例:**
```
音频:
远处有汽车引擎声和喇叭声。脚步踩在湿润路面上的声音。
下水井盖冒蒸汽的轻微嘶嘶声。红绿灯切换的咔哒声。
偶尔有路人经过的模糊交谈声。没有背景音乐。
```

### 7. 目标

回答: 这段素材最终要像什么

**要求:**
- 一句话总结目标效果
- 强调真实感来源

**示例:**
```
目标:
这段素材应该看起来像一个路人用智能手机在纽约街头随手拍到的
早晨通勤片段——不是电影,不是广告,是真实生活中存在过的一个瞬间。
```

## 组合使用

将7个段落组合在一起,就是完整的提示词。AI视频生成模型会根据这些描述来生成视频。

**关键原则:**
1. 真实感来自缺陷和生活细节,不是堆砌风格词
2. 负面约束比正面描述更重要(告诉模型"不要做什么")
3. 时间轴中的非完美事件是去AI感的核心
4. 设备选择决定了画面的基础特征
